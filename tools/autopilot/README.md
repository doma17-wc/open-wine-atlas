# Autopilot (Open Wine Atlas Instagram)

`make.py` renders reels (`reel-cluster`, `reel-vs`), carousels (`carousel`) and stories (`story-teaser`, `story-member`) from a JSON spec in about a minute each: stills of the real atlas map, then ffmpeg. Run it with `OWA_CHROME` set. `music2.py` is the original score (presets japan, warm, dusk, alpine, south). Since 20 Nov 2026 Stefano wants a vintage harpsichord waltz feel in the atlas videos: music2.py now gives that original waltz for every seed that is not a multiple of 3 (the preset sets the key) and the older ambient score for seeds that are multiples of 3, so about two reels in three carry the waltz. Preset `harpsi` always gives the waltz. Never use commercial songs. Note `music: waltz` or `music: ambient` in log.json. `log.json` lists what the daily task made, so topics do not repeat. Quiz carousels and question stories come from `../study_posts/render.py`.

Spec fields: `name`, `eyebrow`, `title`, `sub`, `places` (atlas ids from web/data/search.json; 3 to 7 compact neighbours for a cluster, 2 for vs), `preset`, `seed`, `total` (false when outlines overlap), `no_area` (true for outlines drawn from whole communes), `no_labels` (true hides map labels such as estate names), `maxzoom` (cluster reel, default 13.5; raise to 15 for premier crus or anything under about 3 km across), `member` (replaces the member card text), `image` and `foot` (teaser story), `strip` (cluster reel: text removed from the place names), `rename` (carousel: {atlas name: name to show}; cluster reel: {atlas id: name to show}), `kick_from` and `kick_of` (carousel slide counter). `hook` (reel-cluster and reel-vs: first frame shows every place already drawn with this text in big type, for the 3-second opening), `game` (reel-vs with `hook`: the first frame fits each place on its own so the sizes look alike, e.g. hook "Which one is bigger?", then the same-zoom reveal).

Voice (since 18 Nov 2026 every reel has one): `voice_tts.py lines.json DIR` makes one trimmed Kokoro wav per line (lines.json: `{"voice", "lang", "lines": [{"text", "ph"}]}`; `ph` = IPA override for French, Italian or German names) and prints each duration; set the spec `secs` (card durations: cluster `hook`, `title`, `place`, `total`, `member`; vs `hook`, `both`, `ratio`, `member`) so every line fits its card, re-render, then `voice_mix.py reel.mp4 DIR starts.json out.mp4` (starts = card start + 0.15 s; the cross-fade is 0.35 s) ducks the score about 6 dB under the voice, normalises to -14 LUFS and writes DIR/wave.png for the check.
